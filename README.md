# Dahua Exporter

Программа для выгрузки записей с Dahua NVR/DVR и IP-камер
через официальный HTTP CGI API и RTSP.

Работает **только при прямом сетевом доступе** к устройству —
локальная сеть, VPN или проброс порта. Облако/P2P Dahua
сознательно не используется.

---

## Быстрый старт

### 1. Установить зависимости

Открой командную строку в папке проекта и выполни:

```
py -m pip install requests PySide6 keyring
```

Или, если проект ставится как пакет:

```
py -m pip install -e .
```

### 2. Установить ffmpeg

Нужен для выгрузки видео и работы со звуком.

```
winget install Gyan.FFmpeg
```

**Важно:** после установки закрой и открой терминал заново —
PATH обновляется только в новом окне. Проверка:

```
ffmpeg -version
```

Если команда не найдена — перезагрузись или добавь ffmpeg в PATH вручную.

### 3. Запустить

Дважды кликни по файлу **`Запустить Dahua Exporter.bat`**.

Или из командной строки:

```
py -m dahua_exporter.gui
```

## Ярлык на рабочем столе

Чтобы не искать папку каждый раз:

1. Нажми правой кнопкой на **`Dahua Exporter.bat`**
   (этот файл запускает программу **без чёрного окна консоли**)
2. Выбери **«Отправить» → «Рабочий стол (создать ярлык)»**
3. Найди ярлык на рабочем столе, нажми правой → **«Свойства»**
4. В поле **«Быстрый вызов»** (или «Объект») путь уже верный — ничего менять не надо
5. Нажми **«Сменить значок»** и укажи путь к любой `.ico`-иконке
6. В поле **«Рабочая папка»** убедись, что стоит папка проекта

После этого программу можно запускать двойным кликом с рабочего стола.

### Автозапуск при входе в Windows

Если хочешь, чтобы программа стартовала сама:

1. Нажми `Win + R`, введи `shell:startup`, Enter
2. Положи туда ярлык на `Dahua Exporter.bat`

### Закрепить на панели задач

Запусти программу, затем нажми на её значок в панели задач
правой кнопкой → «Закрепить на панели задач».

## Как пользоваться

### Вкладка «Подключение»

1. **IP** — адрес устройства. Узнать: в DMSS, в веб-интерфейсе
   или в настройках сети на самом NVR
2. **Порт** — обычно **80** (HTTP). НЕ 37777 — это другой протокол
3. **Логин** и **пароль** — учётные данные устройства
4. Поставь галочку **«Запомнить пароль»** — тогда вводить придётся один раз
5. Нажми **«Подключиться и загрузить камеры»**

Если всё верно — увидишь модель устройства, серийник и список каналов.
Индикатор в правом верхнем углу станет **зелёным**.

### Вкладка «Выгрузка»

1. **Канал** — выбери камеру
2. **С** и **По** — интервал записи. Есть кнопки быстрого выбора:
   10 минут, 1 час, 3 часа, сутки (считаются от «По»)
3. **Поток**:
   - *Основной* — полное качество, обычно 4K HEVC
   - *Субпоток* — меньше разрешение, легче и быстрее
4. **Кодек видео**:
   - *Как есть* — быстро, без потери качества, но HEVC не откроется
     в стандартном плеере Windows
   - *H.264* — медленнее, зато играется везде. **Рекомендуется**
5. **Звук** — один из четырёх режимов:
   - удалить полностью
   - убрать левый канал
   - убрать правый канал
   - оставить как есть
6. **«Проверить поток»** — покажет кодек и разрешение до выгрузки.
   Если HEVC, предупредит жёлтым
7. **«Выгрузить»** — выбери, куда сохранить, и жди

Отмену можно нажать в любой момент — программа погасит ffmpeg,
удалит недописанный файл, и можно сразу запускать заново.

## Пароли и настройки

**Настройки** (IP, логин, режимы) хранятся в:

```
C:\Users\<твоё_имя>\.dahua_exporter\config.json
```

**Пароль** туда НЕ пишется. Он уходит в системное хранилище
Windows — «Диспетчер учётных данных». Пароль зашифрован ОС
и привязан к твоей учётной записи.

Чтобы стереть сохранённый пароль — кнопка **«Забыть пароль»**
на вкладке «Подключение».

## Командная строка (для скриптов и автоматизации)

### Показать каналы

```
py -m dahua_exporter.cli --host 192.168.1.108 --user admin channels
```

### Найти записи за интервал

```
py -m dahua_exporter.cli --host 192.168.1.108 --user admin find ^
  --channel 1 --start "2026-09-15 00:00:00" --end "2026-09-15 03:00:00"
```

(символ `^` — перенос строки в cmd; можно писать одной строкой)

### Выгрузить запись

```
py -m dahua_exporter.cli --host 192.168.1.108 --user admin export ^
  --channel 1 --start "2026-09-15 00:00:00" --end "2026-09-15 00:10:00" ^
  --out video.mp4 --subtype 1 --vcodec h264 --audio strip_full
```

Пароль спросит отдельно, если не указать `--password`.

**Важно:** не указывай порт в поле `--host`. Порт задаётся
отдельным параметром `--port` (по умолчанию 80).

## Частые проблемы

### «Нет связи с ... Подключение отклонено»

Неверный IP (это шлюз, а не NVR) или устройство выключено.
Проверь адрес — он должен открываться в браузере по `http://IP`.

### «Неверный логин или пароль (401)»

Проверь учётные данные. На некоторых устройствах Dahua
отдельный пароль для веб-интерфейса и для мобильного доступа.

### «ffmpeg не найден в PATH»

Установи ffmpeg и **открой терминал заново**. PATH не
подхватывается в уже открытом окне.

### «Записей не найдено», хотя запись точно есть

Проверь интервал — возможно, в указанное время записи нет.
Попробуй расширить диапазон. Также учти, что запись могла
идти в **основной** поток, а не в субпоток, и наоборот.

### Файл выгрузился, но не открывается

Скорее всего внутри HEVC, а стандартный плеер Windows его
не умеет. Два решения:
- выбрать кодек **H.264** при выгрузке
- или смотреть через VLC (он играет HEVC из коробки)

Код ошибки `0xc00d5212` — это оно.

### Программа запускается, но окно не появляется

Запусти `Запустить Dahua Exporter.bat` — он оставит окно
консоли открытым и покажет текст ошибки.

### Если порт 80 закрыт

Нужен именно HTTP-порт устройства. Порт **37777** — это
проприетарный протокол Dahua Private SDK, он здесь не
используется. Посмотри HTTP-порт в настройках сети NVR.

## Ограничения

- Облако Dahua (P2P, DMSS) не поддерживается — нужен прямой доступ
- Устройства без HTTP CGI API не подойдут (очень старые модели)
- Формат ответа устройства может отличаться по моделям — если
  поиск записей не работает, запусти `diagnose.py` и посмотри
  сырой ответ (см. раздел про диагностику)
